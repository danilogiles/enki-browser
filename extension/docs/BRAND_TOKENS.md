# Enki brand — silver shield, cyan eyes

**Mark:** a silver shield with a dark visor and two glowing cyan eyes. The shield is the head: a friendly assistant and protection in one shape. It has no plate or background behind it, so it sits on light and dark taskbars alike; a faint dark outline keeps it visible on white. Original artwork for Enki.

The source of truth is `src/assets/logo.svg` (256 × 256 viewBox). If this page and the SVG ever disagree, the SVG wins.

## Mark colors (from `src/assets/logo.svg`)
| Part | Value | Notes |
|---|---|---|
| Shield fill | `#ffffff` → `#dfe7ee` | Vertical gradient, white at the top to silver at the bottom |
| Shield outline | `#0f172a` @ 22%, 7px stroke | Keeps the mark visible on white |
| Visor | `#1e293b` → `#0b1220` | Vertical gradient, rounded pill |
| Eyes | `#38bdf8` + soft glow | Two rounded bars; glow is a Gaussian blur (σ 5) of the same color |
| Highlight | `#ffffff` @ 90%, 8px stroke | Small curved stroke, top left, so the shield reads as glossy, not flat |

Rules for the mark:
- Keep it on a transparent background. No plate, tile, or badge behind it.
- Enki Browser's system icons (exe, installer, taskbar) use the plated version from `enki-browser/brand/`; everywhere else (extension and in-app), no plate.
- The eyes are always sky/cyan `#38bdf8`, whatever theme the panel uses.
- The face is the visor and the two eyes only: no mouth, cheeks, or blush. The earlier happy-face mascot is archived and its face, cheek, and blush colors are retired.
- Don't recolor, stretch, or add effects to the shield; scale the vector.

## UI colors
| Token | Hex | Use |
|---|---|---|
| `enki-sky-400` | `#38bdf8` | The eye color. Primary accent on dark themes: send, links, focus (`--enki-400`) |
| `enki-sky-200` | `#bae6fd` | Secondary text on Enki Navy (`--zinc-300`) |
| `enki-cyan-300` | `#7dd3fc` | Muted text on Enki Navy (`--zinc-400`) |
| `enki-navy-900` | `#0c4a6e` | Enki Navy app background (`--app-bg`, `--ink-950`) |
| `enki-navy-800` | `#075985` | Enki Navy panels (`--ink-900`) |

On light themes the accent darkens to `#0284c7` for contrast.

## Files
- `src/assets/logo.svg`: vector master (256 × 256), used in the side panel and Enki Home
- `public/icons/icon{16,32,48,128,256}.png`: extension icons; 256 is for Enki Browser's Windows taskbar and Start menu at high DPI
- Both are generated by `npm run icons` (`scripts/icons.mjs`). The SVG lives inside that script, so change the mark there and regenerate rather than editing `logo.svg` by hand.

## Panel and Enki Home
Default theme is **System**: neutral light or dark greys following the OS, like the browser around them, with sky (`#38bdf8` dark / `#0284c7` light) as the only accent. The original navy look is the optional **Enki Navy** theme.

## Panel chrome (Enki Navy)
Enki Navy keeps the sky accents (`--enki-*`) and maps the `--ink-*` surfaces to navy (`#0c4a6e` / `#075985`).
